# Roadmap

## Next (weeks)
- Finish anything listed as Not built in what-does-not-work.md
- Bulk accept for claims that are fully verified
- Re-verify claims after an edit
- Option to keep restricted text away from the LLM

## Later (months)
- Real source connectors: Git hosting, chat, ticket tools
- Semantic matching on top of the exact and fuzzy match
- Per-claim access requests from incoming roles
- Multi-reviewer approval
- Single sign-on and a retention policy
- Exportable handover packs

## Principle
Every claim stays linked to a source quote and a human decision. Automation never replaces review.
